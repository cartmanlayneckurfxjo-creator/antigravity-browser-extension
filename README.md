# Antigravity Browser Bridge 🚀

Это расширение для браузера Chrome, которое обеспечивает бесшовную интеграцию между веб-браузером и **Antigravity IDE**. 

Расширение работает как "тонкий клиент" — в нём нет прямой интеграции со сторонними API-провайдерами (OpenAI, Anthropic и т.д.). Вместо этого оно отправляет весь контекст страницы и промпты пользователя напрямую в активную сессию Antigravity IDE, используя протокол **MCP (Model Context Protocol)**.

## 🏗 Архитектура

Система состоит из трёх компонентов:

1. **Chrome Extension (Frontend)**:
   - `sidepanel.js` и `sidepanel.html` — пользовательский интерфейс.
   - Захватывает контекст страницы (текст, выделение, URL, заголовок).
   - Подключается к локальному WebSocket-серверу (`ws://localhost:7842`).

2. **MCP Server (`mcp-server/server.js`)**:
   - Выступает связующим звеном (Bridge).
   - Поднимает WebSocket-сервер на порту `7842` для расширения.
   - Подключается к Antigravity IDE по стандартным потокам `stdio` как MCP-сервер.
   - Предоставляет IDE инструменты для управления браузером (`browser_get_context`, `browser_screenshot`, `browser_click` и др.).
   - Позволяет агенту в IDE напрямую взаимодействовать с открытыми вкладками браузера.

3. **Antigravity IDE (Backend / Client)**:
   - Слушает MCP-сервер и предоставляет агенту доступ к браузерным инструментам.
   - Пользователь даёт текстовые команды прямо в окне IDE (например, *"Сделай выжимку открытой вкладки"*), а агент исполняет их через MCP.

## ⚙️ Установка и запуск

1. Установите расширение в браузере (включите Developer Mode в `chrome://extensions/` и загрузите папку `extension`).
2. Убедитесь, что сервер добавлен в глобальный конфигурационный файл `mcp_config.json` Antigravity IDE:
   ```json
   "antigravity-browser": {
       "command": "node",
       "args": ["C:/путь/до/mcp-server/server.js"]
   }
   ```
3. Перезагрузите Antigravity IDE (или конфигурацию MCP). IDE автоматически запустит `server.js`.
4. Откройте боковую панель расширения в браузере. Вы увидите зеленый статус **Antigravity IDE Ready**.

## 💡 Особенности
- **Отсутствие зависаний SQLite**: Расширение больше не вызывает `agy CLI` в фоне, поэтому база данных текущего разговора не блокируется.
- **Единый контекст**: Вы используете ту же модель, с теми же ключами и настройками, что и в самом IDE.
- **Умный контекст**: При включенной галочке "Context", расширение автоматически прикрепляет к вашему вопросу содержимое открытой вкладки браузера.
